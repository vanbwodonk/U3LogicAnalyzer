# FX2LAFW firmware

Firmware images for libsigrok's `fx2lafw` driver, used by Saleae Logic and
other Cypress FX2(LP)-based logic analyzers. `fx2lafw-saleae-logic.fw` is the
image needed by the Saleae Logic (0925:3881).

The images are GPL-2.0-or-later / LGPL-2.1-or-later and come from the
sigrok-firmware-fx2lafw project:
http://sigrok.org/wiki/Fx2lafw
